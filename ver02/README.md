# Микродом Сервис — лендинг

Статический сайт авторизованного сервисного центра Lenovo (Минск).
Без сборщика и зависимостей: чистый HTML, CSS и ES-модули.

## Структура

```
microdom-service/
├── index.html                  # разметка страницы + спрайт иконок
├── README.md
└── assets/
    ├── css/
    │   ├── variables.css       # дизайн-токены: цвета, шрифты, размеры
    │   ├── base.css            # сброс, типографика, контейнер, утилиты
    │   ├── layout.css          # шапка, навигация, оболочка секций, футер
    │   ├── components.css      # кнопки, карточки, сервисный лист, форма
    │   └── sections.css        # правила конкретных секций (hero, услуги…)
    ├── js/
    │   ├── main.js             # точка входа, инициализация модулей
    │   └── modules/
    │       ├── mobile-nav.js   # мобильное меню
    │       ├── scroll-reveal.js# появление блоков при скролле
    │       └── lead-form.js    # отправка заявки
    └── img/
        ├── microdom-logo.svg   # логотип (используется на странице)
        └── microdom-logo.png   # растровая копия для og:image
```

Порядок подключения стилей в `index.html` важен:
`variables → base → layout → components → sections`.

## Локальный запуск

JS подключён как ES-модули, поэтому нужен любой локальный сервер —
при открытии файла двойным кликом (`file://`) браузер заблокирует модули.

```bash
cd microdom-service
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Если JavaScript не выполнится, страница всё равно останется читаемой:
анимация появления блоков включается только при наличии класса `js`
на `<html>`, а форма отправится обычным способом.

## Соглашения по коду

- **Классы** — по духу BEM: блок (`.svc-card`), модификатор через двойное
  подчёркивание-дефис (`.btn--primary`), состояние через префикс `is-`
  (`.is-visible`, `.is-active`, `.is-done`).
- **JS-хуки** — только через `data-*`-атрибуты (`data-lead-form`,
  `data-nav-toggle`), чтобы переименование классов не ломало скрипты.
- **Цвета и размеры** — только через CSS-переменные из `variables.css`,
  без «магических» значений в компонентах.
- **Иконки** — SVG-спрайт в начале `index.html`, вставка через
  `<svg><use href="#icon-…"></use></svg>`.

## Что доработать перед публикацией

1. **Приём заявок.** Форма пока не отправляется на сервер.
   В `assets/js/modules/lead-form.js` задайте `ENDPOINT` (адрес обработчика)
   — остальной код отправки уже написан.
2. **Домен в мета-тегах.** В `index.html` проверьте `link[rel=canonical]`
   и `og:image` — сейчас там `https://microdomservice.by/`.
3. **Карта.** Встроен Google Maps iframe; при необходимости замените на
   Яндекс.Карты.
